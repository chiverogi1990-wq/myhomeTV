# ТВ Дом — оболочка для Android-приставки в стиле «витрина + ряды плиток»

Сверху приветствие, дата, кнопки «Сеть» и «Настройки», часы. Посередине большая витрина:
её цвет и заголовок меняются под выбранную плитку. Внизу ряды широких плиток:
«Избранное», «Все приложения», «Система».

Пульт: стрелки — выбор, ОК — открыть. Удержание ОК или кнопка «Меню» на плитке —
добавить/убрать из избранного, сдвинуть влево/вправо, сведения, удалить.
Внешних библиотек нет, работает на Android 5–15.

## Как собрать APK без установки программ (GitHub)

1. Зарегистрируйтесь на https://github.com (бесплатно).
2. Справа вверху «+» → New repository → любое имя (например, `tvhome`) → Create repository.
3. На странице репозитория нажмите «uploading an existing file» и перетащите
   **всё содержимое** папки `TvHome` (не саму папку, а то, что внутри,
   включая скрытую папку `.github`) → Commit changes.
   Если `.github` не перетаскивается: Add file → Create new file, в имени напишите
   `.github/workflows/build.yml` и вставьте содержимое этого файла.
4. Откройте вкладку **Actions**. Сборка запустится сама и займёт 3–5 минут.
5. Когда появится зелёная галочка, нажмите на сборку и внизу в разделе **Artifacts**
   скачайте `TvHome-apk`. Внутри архива — `TvHome.apk`.

Пересобрать вручную: Actions → «Собрать APK» → Run workflow.

## Как собрать APK в Android Studio

1. Установите Android Studio (бесплатно): https://developer.android.com/studio
2. File → Open → выберите папку `TvHome`. Дождитесь, пока Studio докачает всё нужное
   (первый раз несколько минут).
3. Build → Build App Bundle(s) / APK(s) → Build APK(s).
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

## Как поставить на приставку

1. Скопируйте APK на флешку и вставьте её в приставку.
2. Откройте файл через любой файловый менеджер (например, X-plore или File Commander).
3. Разрешите установку из неизвестных источников, когда приставка спросит.
4. Нажмите «Домой» на пульте и выберите «ТВ Дом» → «Всегда».

Если приставка не спрашивает, какую оболочку выбрать:
Настройки → Приложения → Приложения по умолчанию → Главный экран → «ТВ Дом».

## Что поменять под себя

- Цвета: `app/src/main/res/values/colors.xml`
- Размер плиток: `app/src/main/res/values/dimens.xml`
- Раскладка экрана: `app/src/main/res/layout/activity_main.xml`
- Название: `app/src/main/res/values/strings.xml`
